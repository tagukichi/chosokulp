# 調速 LP テーマ（chosoku-lp）

不動産調査業務を支援するクラウド型ソフトウェア「調速（ちょーはや）」のランディングページ用 **クラシック WordPress テーマ**。
1ページ完結型で、`v2/` の静的LPをそのまま再現しています。デザイン・アニメーションは静的版と同一です。

## インストール
1. `wp-theme/chosoku-lp/` フォルダを **ZIP 圧縮**（フォルダ名は `chosoku-lp` のまま）。
2. WordPress 管理画面 → **外観 > テーマ > 新規追加 > テーマのアップロード** で ZIP を選択。
   - または `wp-content/themes/chosoku-lp/` に直接配置。
3. **有効化**。トップページにLPが表示されます（`front-page.php`）。
   - 「設定 > 表示設定」で「ホームページの表示」が固定ページの場合も、本テーマは `front-page.php` が優先され同じLPを表示します。

## 「外観 > カスタマイズ > 調速LP設定」で編集できる項目
- **ロゴ・アイコン**：
  - ヘッダーロゴ … 「調速LP設定 > ロゴ・アイコン」または **標準の「サイト基本情報 > ロゴ」** のどちらからでも変更可（優先順：サイト基本情報 → 調速LP設定 → 同梱）。
  - フッターはヘッダーと同じロゴを表示します。
  - ブラウザのタブに出る**アイコン（ファビコン）** … 「サイト基本情報 > サイトアイコン」で設定（WP標準機能）。
- **「選ばれる理由」画像**：01〜06。未設定の項目は同梱のアプリ画面画像（`assets/img/screens/why-*.jpg`）を表示。
- **お問い合わせフォーム**：Contact Form 7 のショートコードを貼ると、その場所にCF7フォームを表示。空ならデザイン用ダミーフォーム。
- **リンク・URL**：ログイン（本体アプリ・既定 `https://app.cho-haya.com/`）/ プライバシーポリシー / 特商法表記 / 運営会社。
- **SEO / OGP**：メタディスクリプション、OGP画像。

## Contact Form 7 連携手順
1. プラグイン「Contact Form 7」を有効化。
2. 「お問い合わせ > 新規追加」でフォームを作成（通知先メールはCF7のメールタブで設定）。
3. 発行されたショートコード（例 `[contact-form-7 id="123" title="お問い合わせ"]`）を
   **カスタマイズ > 調速LP設定 > お問い合わせフォーム** に貼り付け。
   - 同梱の `assets/css`（テーマ style.css 内）に `.contact-form` のスタイルがあるため、
     CF7 のマークアップに合わせて微調整したい場合は CSS を追記してください。

## よくある質問（FAQ）を固定ページから編集する（ACF）
FAQ は **ACF（Advanced Custom Fields・無料版）** で、ホームページに設定した固定ページの編集画面から入力できます（繰り返しフィールドは使っていません）。

セットアップ：
1. プラグイン「**Advanced Custom Fields**」（無料版）をインストール・有効化。
2. **設定 > 表示設定** で「ホームページの表示」を**固定ページ**にし、トップ用の固定ページを選択。
3. その固定ページを編集すると、**タイトル直下に「調速LP コンテンツ」**が表示されます。
4. 「よくある質問（FAQ）」タブで FAQ1〜8 の質問・回答を入力 → 更新。

仕様：
- **質問を空欄にした項目は非表示**になります（最大8件、件数はこれで調整）。
- **すべて空欄ならテーマ既定の6件**を表示します（プラグイン未導入時も同様）。
- 回答内の改行はそのまま反映されます。
- ACF が無効でもテーマは通常どおり動作します（既定のFAQを表示）。

### 「特長（01-04）」セクションもACFで編集
「調速LP コンテンツ」の **「特長（01〜04）」タブ**で、セクション見出しと 01〜04 の
各タイトル・説明・チェックリスト（各3項目）・画像を編集できます。チェックリストは空欄の項目を非表示にでき、
未入力の項目は既定の文言・画像を表示します。02 の右側はAIの作成アニメーション（固定）のため画像欄はありません。

### 「選ばれる理由」セクション（01-06）もACFで編集
「調速LP コンテンツ」の **「選ばれる理由（テキスト）」タブ**で、セクション見出しと 01〜06 の
各タイトル・説明文を編集できます（画像はカスタマイザーの「「選ばれる理由」画像」）。未入力なら既定文を表示します。

### 「案件管理表」セクションもACFで編集
同じ「調速LP コンテンツ」の **「案件管理表」タブ**で、以下を編集できます：
- 見出し／説明文
- 3つのカード（案件管理・顧客管理・ポートフォリオ）… タイトル・説明文・ポイント3つ・画像
- カードの下の一文
- 任意のメディア … **動画URL（YouTube/Vimeo/mp4）→ 動画ファイル → 画像** の優先で、見出しの下に表示。すべて未設定なら表示しません。

### アップデート時の注意（v1.2.0）
- **利用規約のページテンプレートを削除**しました。WordPress で「利用規約」テンプレートの固定ページを作っている場合は、その固定ページを非公開または削除してください（残すとLPと同じ内容が表示されます）。
- フッターのロゴはヘッダーと同じ横ロゴになりました（カスタマイザーの「フッターロゴ（縦）」は廃止）。
- FAQ の既定から「解約はできますか？」を外しました（ACF で入力済みなら、その欄を空にしてください）。

### アップデート時の注意（v1.1.0）
ACF の各欄に**以前の文言を入力したまま**だと、そちらが優先されて新しい既定文が表示されません。
とくに次の欄は内容が変わっているため、入力済みなら**空欄に戻す**（または新しい内容に書き換える）ことをおすすめします。
- 特長 01〜04（タイトル・説明・チェック）、選ばれる理由 01（旧「公的データ100%」）
- FAQ（旧「具体的な金額数値は表示されますか？」「解約はいつでも可能」など）
- 案件管理表の見出し・説明文（旧「案件管理「kanri」と、ひとつながり。」）
- 旧「チェックリスト1〜4」の欄は使われなくなりました（入力内容は表示されません）

> 機能・選ばれる理由・お悩み等のテキストも同じ方式（固定フィールド）で編集可能にできます。必要なら拡張します。

## アクセス解析（GA4）
- 「サイトキット」等のプラグイン、または子テーマ/フック（`wp_head`）で GA4 タグを追加してください。

## 構成
```
chosoku-lp/
├─ style.css            テーマヘッダー＋LP全スタイル
├─ functions.php        セットアップ・アセット読込・ヘルパー
├─ header.php           <head>／ヘッダーナビ（ロゴはカスタマイザー対応）
├─ footer.php           フッター（各URLはカスタマイザー対応）
├─ front-page.php       トップ＝LP
├─ index.php            フォールバック（同じくLP）
├─ inc/customizer.php   カスタマイザー設定
├─ inc/acf-fields.php   ACF フィールド（固定ページで編集する項目）
├─ template-parts/lp.php  LP本体（全セクション）
└─ assets/
   ├─ css/（※スタイルは style.css に内包）
   ├─ js/lp.js          メニュー/リビール/AIの作成アニメーション 等
   └─ img/              logo-chohaya.png（ヘッダー・フッター共通ロゴ）, screens/（アプリ画面画像）
```

## 備考
- 静的版は `/v2/`（GitHub Pages 配信）に残しています。デザイン変更は静的版→本テーマの順で反映すると差分管理が楽です。
- 子テーマでのカスタマイズを推奨（本テーマ更新時に上書きされないため）。
